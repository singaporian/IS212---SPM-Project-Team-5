# US-006 / US-019 / US-033 / US-018 automated coverage

Browser E2E covers critical user journeys through the real Vue app, HTTP API and PostgreSQL.
Integration tests cover API/database rules, authorization, boundaries, rollback and concurrency.
Frontend component tests remain a separate layer; they are not browser E2E tests.

## Commands

From the repository root:

```powershell
cd backend
node --test test/integration/submissions.test.js test/integration/booking.review.test.js test/integration/booking.decisions.test.js test/integration/booking.notes.test.js
npm run test:integration
npm test
cd ../e2e
npm run lint
npm run test:smoke
```

E2E prerequisites: backend/frontend dependencies, `npm ci` in `e2e`, Playwright Chromium (`npx playwright install chromium`), local PostgreSQL and initialized schema. Playwright starts the real backend/frontend when the configured ports are free. Do not reseed the database during execution.

Fixtures use unique users, events and venues. Cleanup removes notifications for fixture events before deleting those events, including events created by fixture Organisers through the browser. Other application records are retained. No approval/status/notification production rules are changed by this test work.
